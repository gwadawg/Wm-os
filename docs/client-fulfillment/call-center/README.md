# Client Fulfillment — Call Center

Rules for fulfillment call-center reps. These pages are how the floor works, across every offer the call center dials (reverse mortgage, DSCR, home equity, and any offer added later).

**Not this folder:** Waiz selling Waiz. That work stays in [Acquisition Sales](../../acquisition/sales/README.md).

## Who uses this

Reps on a shift, anyone writing a new script, and anyone building training from the rules. Company process docs (owners, scorecards, team Drive copies) come after this knowledge base.

## Rules

One owner per idea. If a script and a rule disagree, the rule wins.

| Doc | Owns |
|-----|------|
| [Representation](representation.md) | Who the rep is |
| [Call framework](call-framework.md) | Stage order, and why each stage exists |
| [Call flow](call-flow.md) | Live transfer or book |

| [Dial cadence](dial-cadence.md) | When and how often a lead gets dialed |

## After the call

Booking reminders are the next layer. They are not rep rules. The rep books on a Waiz number, and a separate sequence reminds the lead that the call with the client is coming up. Those messages still speak as the client's assistant.

| Offer | Doc |

## Where a file lives

Universal rules stay in this folder. They do not change by offer.

The live-transfer script stays here too. It is the same hand-off for every client.

Both offer scripts live here. Do not make a second copy in a product pod.

| What | Where |
|------|--------|
| [Live Transfer](script-live-transfer-warm-handoff.md) | This folder. Words for the hand-off. |
| [RM Call Script](script-rm-appointment-setting-call.md) | This folder. Reverse mortgage only. The Drive copy is the previous script until it is republished. |
| [DSCR Call Script](script-dscr-appointment-setting-call.md) | This folder, next to the RM script. |
| [DSCR Team Product FAQ](../dscr-dna/dscr-team-product-faq.md) | Product training. Not a call-center rule. |
| [RM Borrower Objections](../reverse-mortgage-dna/rm-borrower-objections.md) | Cross-channel objection reference. Call wording is in the RM script. |

The scripts are the words only.
