# Swipe: Comment-reply hook + stressed senior B-roll

## Why it stopped me

TikTok-native comment reply creates parasocial curiosity before any product mention; stress visual does pain work silently.

## Script decomposition (rubric A)

- Hook type: Comment reply / curiosity gap
- First 5 seconds: Stressed senior at table + "What's the smartest money decision you ever made?"
- Structure: Pain visual hold → implied answer (watch to learn)
- Frame mechanic: Community question positions creator as trusted advisor
- Retention devices: Comment bubble UI; paperwork on table
- CTA style: Soft — watch for answer
- Voice / talent: B-roll subject + reply overlay (no VO in frame)
- Funnel stage: TOF

**Named pattern:** `comment-reply-pain-broll`

## Editing decomposition (rubric B)

- First frame: Medium close-up, head in hand, papers on table
- Cut frequency: Slow hold on pain before answer
- Caption style: TikTok reply card, bold question text
- B-roll ratio: 100% b-roll in opening
- Pattern interrupts: Native comment UI
- Audio bed: Tense neutral under pain
- Pacing-to-copy: Let emotion land 2–3s before cut
- Production tier: Stock/b-roll + overlay

**Named style:** `native-comment-overlay`

## Scores (optional)

- Scroll-stop strength: 4/5
- Clarity: 3/5 (answer must deliver in follow frames)
- RM transferability: 5/5

## RM adaptation note

Do not use age in copy. Answer beat must stay educational, not product-named at TOF. Strong for Financially Squeezed + Legacy Planner archetypes.
