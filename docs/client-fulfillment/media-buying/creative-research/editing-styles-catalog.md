# Editing Styles Catalog (RM Video)

Reusable **editing styles** distilled from decomposed swipes. Each style is a recipe
the team can hand to an editor. Populate from `swipes/` via the editing rubric.

> RM reality: the 62+ feed rewards warmth, clarity, and calm over hype. Fast-MrBeast
> pacing often *fails* here. Capture the style anyway, but the RM adaptation column is
> where the real value is.

## How to add a style

1. Decompose 2–3 swipes that share an editing approach (rubric B).
2. If they share a recipe, name it and add a row.
3. Fill the **RM adaptation** column — check against
   [RM Compliance Guardrails](../../reverse-mortgage-dna/rm-compliance-guardrails.md).
4. Link the source swipe file(s).
