# Script Archetypes Catalog (RM Video)

Reusable **script patterns** distilled from decomposed swipes, mapped to our 6 archetypes
and the TOF/MOF/BOF framework in the [RM Ad Playbook](../../client-marketing/rm-ad-playbook.md).
Populate from `swipes/` via the script rubric.

## Archetype entries

| Pattern name | Hook type | Structure | Frame mechanic | CTA style | Funnel stage | Best for archetype | Compliance note | Source swipe |

| | | | | | | | | |

## How to add an archetype

1. Decompose 2–3 swipes that share a script structure (rubric A).
2. Name the pattern by its dominant move (hook + emotional driver).
3. Map to archetype(s) and funnel stage.
4. Add the compliance note (no product name in TOF, no guarantees, no urgency, no age in copy)
   per [RM Compliance Guardrails](../../reverse-mortgage-dna/rm-compliance-guardrails.md).
5. Link the source swipe file(s).
