# Swipe Decomposition Rubrics

Run every captured swipe through the relevant rubric. The output of each rubric is a
**named, reusable pattern** — not a description of one ad.

---

## A. Script decomposition (what it says)

| # | Dimension | What to capture |
|---|-----------|-----------------|
| 1 | **Hook type** | rhetorical question / shock statement / confessional / demonstration / niche callout / authority / curiosity gap / social proof / specific pain / paradox |
| 2 | **First 5 seconds** | Exact words. Test: is it about the *prospect* or the *speaker*? (speaker = fail) |
| 3 | **Structure** | Which beats, in what order, seconds each (e.g. Hook→Empathy→Frame Shift→Proof→CTA) |
| 4 | **Frame mechanic** | What belief does it shift? Debt Frame → Retirement Tool Frame? How? |
| 5 | **Retention devices** | Open loops, "but here's the thing", callbacks, numbered lists, escalation |
| 6 | **CTA style** | Direct ("book a call") vs info-access ("get the free guide"); friction level |
| 7 | **Voice / talent** | LO to camera / UGC customer / actor / voiceover; tone |
| 8 | **Funnel stage** | TOF / MOF / BOF (and does it obey that stage's rules?) |

**Output line:** `[confessional-hook + empathy-heavy + info-CTA], TOF, shifts Debt→Tool frame via "already earned" reframe`

---

## B. Editing decomposition (how it's made)

| # | Dimension | What to capture |
|---|-----------|-----------------|
| 1 | **First frame (0:00)** | Face? Text? Motion? Pattern break? What stops the scroll visually |
| 2 | **Cut frequency** | Cuts per 10s — fast (UGC, 6–10) vs slow (authority, 1–3) |
| 3 | **Caption style** | Burned-in? Word-by-word karaoke? Font / color / position / size |
| 4 | **B-roll ratio** | Talking-head vs cutaways; what kind of cutaways (home, lifestyle, graphics) |
| 5 | **Pattern interrupts** | Zoom punches, text pops, SFX, location/wardrobe changes, speed ramps |
| 6 | **Audio bed** | Music? Voiceover? Raw/ambient? Trending sound? |
| 7 | **Pacing-to-copy** | Does the cut change when the *message beat* changes? |
| 8 | **Production tier** | Phone-UGC / prosumer / studio |

**Output line:** `fast-UGC-confessional: phone-shot, ~8 cuts/10s, word-by-word yellow captions, no b-roll, raw audio, zoom-punch on hook`

---

## Scoring (optional, for sharper capture)

For each swipe rate 1–5 on:
- **Scroll-stop strength** (did the first frame/hook earn the next 3s?)
- **Clarity** (one idea, understood fast?)
- **RM transferability** (can this survive the 62+ feed + compliance?)

Only patterns scoring 4–5 on transferability get codified into the catalogs.
