# Creative Studio Compliance Gate Checklist

Every concept and script the studio produces runs through this gate before it is shown as
ready. It combines the non-negotiable [RM compliance guardrails](../../reverse-mortgage-dna/rm-compliance-guardrails.md)
(founder-owned, `active`), the playbook prohibitions, and the DR quality rule.

> Output rule: any FAIL means the asset stays `draft` and is fixed or flagged for human review.
> Never present a failing asset as final.

## Part A — Hard compliance (any FAIL = block)

Source: [rm-compliance-guardrails.md](../../reverse-mortgage-dna/rm-compliance-guardrails.md) + playbook Section 6.

- [ ] **No product name in TOF.** "Reverse mortgage" / "HECM" never appears in a TOF headline, hook, body, or CTA.
- [ ] **No age in copy.** Use "retired homeowners" / "homeowners in retirement." Age (62+) is an eligibility/targeting fact only.
- [ ] **No guaranteed outcomes.** Use "may qualify," "could access," "in many cases." Never "you will qualify," "get $X."
- [ ] **No tax advice claims.** No "tax-free," "no tax consequences." Tax treatment depends on the individual.
- [ ] **No false urgency / scarcity.** No "act now," "last chance," "limited time." Ethical, advisor-framed urgency only (ICP §9).
- [ ] **No fabricated testimonials or statistics.** Proof is real or clearly hypothetical.
- [ ] **No pity / desperation / crisis imagery.** Dignity standard; no distressed-senior stock framing.
- [ ] **No protected-class exclusion.** Special Ad Category — no targeting/copy that excludes protected classes.
- [ ] **No financial advice.** Encourage speaking with a qualified professional where relevant.
- [ ] **Program name disclosed succinctly** when appropriate/required — never as the headline.

## Part B — Stage discipline (any FAIL = fix)

Source: playbook TOF/MOF/BOF + [frameworks-reference awareness bridge](frameworks-reference.md).

- [ ] TOF leads with the prospect's world; product does not exist yet; no product name.
- [ ] MOF introduces the category only after the Retirement-Tool frame is set; proactively busts myths.
- [ ] BOF positions the LO as the expert; direct conversation CTA; product named openly.

## Part C — Quality rule (DR doctrine, any FAIL = stays draft)

Source: [frameworks-reference.md §F1](frameworks-reference.md). Copy without all four stays draft, not final.

- [ ] **VOC** — uses the prospect's actual language (ICP §5), not company language.
- [ ] **Mechanism** — names the root cause / how it works in one sentence; not a bare promise.
- [ ] **Proof** — specific (name, number, context, before/after) or clearly hypothetical.
- [ ] **Awareness** — hook and frame match the concept's awareness/stage.

## Part D — Hook & CTA hygiene

- [ ] Hook passes the "prospect or speaker?" test (first words are for the prospect).
- [ ] First 5 seconds (video) work without "Hi, I'm [name] from [company]."
- [ ] CTA is from the approved bank (TOF/MOF info-access; BOF direct invite) and low-friction.

## Part E — Format-specific (testimonial + educational only; any FAIL = fix)

Source: [higgsfield-format-modules.md](higgsfield-format-modules.md). Skip this part for UGC,
static, and long-form real-talent formats.

**Testimonial (spoken or silent text-overlay):**

- [ ] **Dramatization disclosure documented** in Editor Notes with placement
      (`Dramatization. Composite of real homeowner experiences. Individual results vary.`) —
      burned in by the editor, never AI-rendered.
- [ ] **Story tagged Composite.** Speaker is never presented as a real named client.
- [ ] **No result dollar figures.** Numbers stay on the struggle side; a real, approved client
      result is `[TO FILL]` → **HUMAN REVIEW**.

**Educational / explainer:**

- [ ] **Explains, never advises.** No "you should" recommendations; "talk to a qualified
      professional" framing where relevant.
- [ ] **B-Roll Sourcing Plan present**, every scene tagged GENERATE / SOURCE / EDITOR.
- [ ] **Every SOURCE item flagged for licensing check** (licensed stock or client-approved
      footage only — never grabbed from the open web).

## Part F — Product line fit (any FAIL = block or rewrite)

Source: [rm-product-lines.md](../../reverse-mortgage-dna/rm-product-lines.md).

- [ ] **Client product confirmed.** Concept tags `product: hecm` | `product: homesafe-second` | documented in brief.
- [ ] **No "keep your rate / don't refinance" on HECM-only clients.** HECM typically pays off the first lien — refi-vs-keep-rate comparison ads and **Leave first rate** silent spines are **HomeSafe Second only**.
- [ ] **No HECM/FHA claims on proprietary lines.** HomeSafe Second is not HECM; do not cite FHA insurance or HECM counseling unless accurate for that product.
- [ ] **Payment elimination copy matches lien position.** "Mortgage payment eliminated" = HECM first-lien story. HomeSafe Second = no required payment on the **second** lien; first lien payment remains.
- [ ] **State / age claims** match the product being sold (HECM 62+ vs HomeSafe Second state-varying floors).

## Result block (paste into each output)

```
Compliance Gate
A Hard:    PASS / FAIL -> <which item>
B Stage:   PASS / FIX
C Quality: PASS (VOC / mechanism / proof / awareness all present?) / DRAFT
D Hygiene: PASS / FIX
E Format:  PASS / FIX / N/A (testimonial + educational formats only)
F Product: PASS / FAIL -> <which item> (see rm-product-lines.md)
RESULT: READY  |  DRAFT (reason)  |  HUMAN REVIEW (reason)
```

## Escalation

- Borderline claim or anything touching loan terms, rates, or amounts -> flag **HUMAN REVIEW**, do not auto-pass.
- Compliance guardrails are founder-owned; when in doubt, the stricter reading wins.
