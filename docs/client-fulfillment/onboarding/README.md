# Client Fulfillment — Onboarding

Post-close client launch: five stages from Client Activated through Account
Live. Status fields and the Launch Gate live inside a stage and do not move
the client on their own.

**Stage truth:** [Client Onboarding Blueprint](client-onboarding-blueprint.md).
ClickUp and SOPs use those exact stage names. QA forms write the exact
Pending / Complete status fields defined there.
