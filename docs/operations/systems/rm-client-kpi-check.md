We need to be tracking clients KPIs consistently so we can catch a under performing account before it gets worse and client complains. The KPI we optimize for is Cost per conversation. Reason being is that this is a prerequisite on the results the client gets. From there, we can diagnose why the client isn't performing. You can access the client KPI dashboard on the link below
