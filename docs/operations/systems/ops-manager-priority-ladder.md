## Operations Manager Priority Ladder
## Operations Manager Priority Ladder
## Primary Success Metric: System Reliability
Core Principle: Ops build systems — they do not become the system.

## Purpose
If you are ever unsure what to work on, follow this order. Higher priorities always take precedence over lower ones.

## Priority 1 — System Fires / Broken Infrastructure
Anything that breaks the system or prevents clients from receiving leads or appointments.

Examples:

## Broken CRM automations
## Lead routing issues
## Calendar booking errors
## API / integration failures
## Form submissions not working
## SMS or email automation failures
## Lead delivery problems
## Zap / Make automation failures
Rule: These issues must be identified and addressed immediately. If the fix requires additional investigation, acknowledge the issue and begin troubleshooting right away.

Goal: Resolve the same day whenever possible.

## Priority 2 — Client Onboarding
Setting up new clients so they can start receiving leads and appointments.

Examples:

## CRM setup
## Pipeline configuration
## Calendar setup
## Integrations
## Lead routing
## Onboarding automations
## Call center configuration
## System testing before launch
Rule: New client onboarding should move quickly and smoothly.

Goal: Complete onboarding as fast as possible without sacrificing quality. A new client waiting for setup is a top operational priority.

## Priority 3 — Assigned System Tasks / Goals
Tasks assigned in ClickUp related to systems, infrastructure, or improvements.

Examples:

## Updating workflows
## Improving CRM structure
## Updating automations
## Fixing minor bugs
## Updating integrations
## Internal system projects
Rule: Assigned tasks should move forward every day. If blocked, communicate the blocker immediately.

## Priority 4 — Supporting Other Departments
Helping other team members solve system-related needs.

Examples:

## Client success reporting issues
## Marketing tracking setup
## Media buyer pixel issues
## Call center technical issues
## Dashboard fixes
## Team system questions
Rule: Only address these once priorities 1–3 are clear. However, if a request could impact client performance, escalate it to priority 1 or 2.

## Priority 5 — System Optimization / Infrastructure Improvements
Improving the systems and infrastructure of the business.

Examples:

## Improving automations
## Reducing manual work
## Optimizing workflows
## Improving reporting dashboards
## Building new tools
## Improving onboarding systems
## Documenting processes
Rule: Focus on these improvements only when the system is stable and no urgent tasks exist. This is long-term improvement work.

## Daily Execution Rule
When deciding what to work on:

## Check for system fires
## Check for new client onboarding tasks
## Work on assigned system tasks
## Help other departments with system needs
## Improve infrastructure and automation
Always move top → down through the ladder.

## The Ops Mindset: Builder vs. Fixer
Bad Ops Behavior:

## Manually fixing the same thing repeatedly
## Patching issues constantly
Good Ops Behavior:

## Identifying root causes
## Building systems so issues don't happen again
