# Media Buyer Daily OS (Christian)

## Purpose

Keep Christian focused: media buying most days (CPL, CPQL, Opt-in %); onboarding tech on named days; clear notes to Laura. Canonical: [Role Clarity Lane Map](../../plans/2026-07-15-role-clarity-lane-map.md).

## Scope

Christian. Creative is out of scope (CEO). Client relationship calls are Laura’s. Basic stack bugs (AI bot, Hot Prospector, booking/GHL) are Pedro first → Laura → then you. **Exception:** clear **OB setup errors** come to you **direct**.

## Mission

Assigned accounts hit **CPL, CPQL, Opt-in %**. On Mon/Thu you name the fix for reds; Laura follows up. Onboarding tech is done right on named days, self-certified, and handed to Laura clean.

## Not Your Job

- Client relationship / check-in calls (Laura)
- Creative production (CEO)
- Managing setters (Pedro)
- **First-line** AI bot, Hot Prospector, booking/GHL automation, drip/scripts (Pedro → Laura → you)
- Inventing client messaging (Laura)
- P2 onboard/bugs outside Tue/Wed AM (P0/P1 only as interrupt rules above)

## Operating Model

**Buy-default week + 2 protected tech blocks + interrupt rules.**  
You sequence freely *inside* a buy block. You do not invent new work from every Slack ping.

### Protected tech blocks (fixed)

| When | Mode |
|------|------|
| **Tue AM** | Tech — Laura’s onboard/bug queue only |
| **Wed AM** | Tech — Laura’s onboard/bug queue only |
| All other time | **Buy-default** |

### Interrupt classes

| Tier | Example | Rule |
|------|---------|------|
| **P0** | Same-day launch; ads not delivering; pixel/account broken | Drop current work → fix → note to Laura. Valid interrupt. |
| **P1** | Onboard launching in next 48–72 hrs on the board | Use tech blocks first; if no capacity, Laura/Planning moves the launch date — don’t silently burn every buy day. |
| **P2** | Non-urgent bugs / setup | **Only** Tue AM / Wed AM |

If P0 hits more than ~2–3× in a week → raise on **Mon Planning** (system/timeline problem, not “be more flexible”).

### Buy-default blocks

| Block | Focus |
|-------|--------|
| Start (15 min) | Triage: any P0? else account pulse — delivery, spend, **CPL / CPQL / Opt-in %** |
| Core | Optimize / launch / pause · document what changed |
| Before KPI days | Short notes to Laura on reds + what you’re doing |
| End (10 min) | Tomorrow’s priorities · anything Laura must tell a client |

### Tue AM / Wed AM (tech)

| Block | Focus |
|-------|--------|
| Start | Pull **Laura’s queue** only — no drive-by Slack scope creep |
| Core | Onboarding build + bugs · checklist top to bottom |
| Before handoff | **Self-cert checklist** — you own quality |
| End | Mark ready for Laura’s light gate · flag blockers on the OB board |

## Priority Stack

### Buy-default

1. **P0** interrupts (same-day launch / broken delivery)
2. Accounts missing **CPL / CPQL / Opt-in %** targets
3. Planned tests / optimizations
4. Notes for Laura (reds before Mon/Thu KPI — named commitment she can follow up)

### Tech blocks (Tue/Wed AM)

1. P1 onboard builds (nearest launch date)
2. Bugs blocking a live client
3. Checklist cert + handoff to Laura
4. P2 tech debt only after the above

## Meetings You Attend

| When | Meeting | Your job |
|------|---------|----------|
| Mon | KPI → then Ops Planning | Your reds + OB tech timeline — [KPI Review Meeting SOP](kpi-review-meeting-sop.md) |
| Thu | KPI | Your reds + next actions — same SOP · [Under-KPI Ladder](under-kpi-diagnosis-ladder.md) |
| Fri | Exec Q&A | Pre-submit questions only |

## Escalation

Canonical map: [Role Clarity Lane Map](../../plans/2026-07-15-role-clarity-lane-map.md).

| Situation | Who |
|-----------|-----|
| Client messaging / launch call timing / commitment follow-up | Laura |
| AI bot / Hot Prospector / booking·GHL (Pedro already tried → Laura tried) | **You** — next rung |
| Clear OB setup / checklist error | **You direct** (do not wait for Pedro) |
| Lead → appointment volume / dial goals / show / booking % | Pedro (via Laura rollup) — not your first inbox |
| Checklist can’t be completed / system gap | Mon Planning (CEO systems) |
| Creative needed | CEO (not you inventing creative) |

## Done For The Day Means

### Buy day

- [ ] Priority accounts reviewed
- [ ] Changes logged
- [ ] Laura has what she needs for reds / client updates

### Tech block (Tue/Wed AM)

- [ ] Queue items worked in date order
- [ ] Checklist self-cert done or blocker named
- [ ] Laura can gate / schedule launch without chasing you
