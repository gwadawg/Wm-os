# Call Center Manager Daily OS (Pedro)

**Who this is for:** Pedro (Rio) — Call Center Manager
**Use this as:** your role map + daily operating sheet (one source of truth)
**Pay:** out of scope for this doc (handled 1:1 separately)
**Graded by:** the [CCM Role Scorecard](call-center-manager-role-scorecard.md)
(monthly)

Canonical lanes: [Role Clarity Lane Map](../../plans/2026-07-15-role-clarity-lane-map.md).

---

## 1. Why this seat matters

After a lead exists, **your floor** turns attention into booked
appointments. Ads can fill the top of the funnel. Client Success can
keep the relationship healthy. Neither can fix a soft call center.

If Booking %, Show %, and dial goals slip:

- Clients feel the product is broken
- Under-KPI logos stay under-KPI
- Laura and the CEO get pulled into your floor

Your job is to make sure that does not happen — every workday.

---

## 2. Your mission

Every client’s leads can become booked appointments.

- Reps **show up on time**, are **dialing**, and are **on track to
  their daily dial / booking goals** — you own that, not Laura
- Booking % and Show % hold
- Under-KPI clients get scheduled dial focus
- AI bot, Hot Prospector, and booking/GHL automation work — or the
  bug has an owner and ETA
- When the company needs setters, you help with recruitment

---

## 3. You own / not your job

### You own

| Area | What that means |
|------|-----------------|
| **Floor KPIs** | Booking %, Show %, rep dial requirements / goals hit |
| **Attendance + activity** | Reps **show up on time**, stay on the dialer, and stay **on track to today’s goals** — catch late / idle early and fix it the same day |
| **People** | Coach Bernardo & Lukka; run daily training; answer questions |
| **Schedule** | Dialing the **right accounts**; under-KPI logos get dial coverage |
| **Stack bugs (first line)** | AI bot, Hot Prospector, booking / GHL automation, dialer / scheduling blockers |
| **Conversion systems** | Drip / scripts for lead → appointment (when the floor is stable) |
| **Reporting** | Mon/Thu reds + a **named commitment** Laura can follow up |
| **Recruitment (as needed)** | Help source, screen, and train new setters when leadership asks |

### Not your job

- Client check-ins / OB-launch relationship calls → **Laura**
- Ads, Meta/funnels, landing pages, pixels, CPL / CPQL / Opt-in % →
  **Christian**
- Clear OB setup errors → **Christian direct** (skip the long ladder)
- Being “general company tech” outside lead → appointment
- Waiting for Laura to invent your day — you own what to do to hit
  your KPIs; she follows up on what you commit

### Who you work with

| Person | Relationship |
|--------|----------------|
| **Bernardo & Lukka** | Report to you. You own their day. |
| **Laura** | Captures your KPI commitments and follows up. Helps on bugs only after you are stuck. |
| **Christian** | Ads / funnels / OB setup. Not your first-line for bot/GHL unless Laura escalates. |
| **CEO** | Exceptions, doctrine, major rebuilds — Fri Q&A or urgent Planning only |

---

## 4. How to organize your day

Same shape every day. Meetings change *when* you pause — not the
priority order.

| Block | Focus |
|-------|--------|
| **Daily training** (15–20 min) | Numbers → one coaching focus → today’s dial targets / which accounts |
| **Core day** | Keep reps on time + dialing + on pace · floor coaching + QA · unblock stack bugs · schedule under-KPI accounts · recruitment tasks if assigned |
| **Mon / Thu** | KPI check — Booking/Show/dial reds + named commitment for Laura |
| **Mon (as needed)** | Ops Planning if capacity or system design needs CEO |
| **Fri** | Exec Q&A — pre-submit questions only |
| **Shutdown** (10 min) | Setter EOD · scoreboard · open bugs logged with ETA (or escalated) |

---

## 5. Priority stack (always)

Work top → bottom. Do not drop to a lower item while a higher one is
on fire.

1. **Live booking blockers** — AI bot / Hot Prospector / GHL / dialer
   / reps can’t book
2. **Live setter fires** — late / missing / idle / wrong account /
   stuck leads / no-shows protocol
3. **Daily training + KPI coaching** — never skip
4. **Dial + goal pace** — mid-day check that reps are dialing and on
   track to today’s targets; correct before EOD
5. **Under-KPI account dial focus** — schedule reps onto logos that
   need it
6. **Floor coaching / QA** — quality, not only dial count
7. **Conversion systems** — drip/script updates when 1–6 are stable
8. **Recruitment support** — when leadership has asked for help
   (sourcing, screens, training) — after the floor is stable
9. **Report reds to Laura** — before/at KPI with a named next action

---

## 6. Daily checklist

### Start of day

- [ ] Open scoreboard / yesterday’s Booking % · Show % · dials
- [ ] Know which accounts are under KPI (need dial focus today)
- [ ] Confirm Bernardo & Lukka **showed up on time** / are scheduled
- [ ] Glance at open AI bot / Hot Prospector / GHL bugs
- [ ] Run **daily training** (15–20 min): one focus + today’s dial
      targets + account assignments

### Core day (priority order)

- [ ] Clear live booking blockers first
- [ ] Catch late / missing / idle setters same block — get them dialing
- [ ] Mid-day pace check: are reps on track to today’s dial /
      booking goals? Correct if not
- [ ] Coach / QA on the floor — quality, not only dial count
- [ ] Schedule dial coverage onto under-KPI logos if needed
- [ ] If assigned: move recruitment tasks (post, screen, or train)
- [ ] Only when floor is stable: drip / script improvement work

### Mon / Thu (KPI)

Cadence: [KPI Review Meeting SOP](kpi-review-meeting-sop.md) · [Under-KPI Ladder](under-kpi-diagnosis-ladder.md)

- [ ] Bring Booking % / Show % / dial reds
- [ ] Name one commitment per red Laura can follow up
- [ ] Do not wait for Laura to invent your fix
- [ ] If diagnosing mid-week, use the Under-KPI ladder (system vs quality)

### End of day

- [ ] Training ran (or exception noted)
- [ ] You know if each rep **hit dial targets** (or why not + fix)
- [ ] Late / no-show / idle issues were handled same day — not left
      for Laura
- [ ] Open stack bugs have owner + ETA **or** are escalated
      (Laura → Christian)
- [ ] Under-KPI clients have dial coverage scheduled if needed
- [ ] Mon/Thu reds + commitments logged for Laura
- [ ] No setter left without a manager for the day
- [ ] Recruitment asks (if any) have a next step or ETA

## 7. Setters (Bernardo / Lukka)

You own their day. They follow the
[Setter Daily Checklist](../../acquisition/sales/setter-daily-checklist.md)
and submit EOD per the
[EOD Report SOP](../../acquisition/sales/eod-report-sop-setters-closers.md).
Your job:

- Set today’s numeric dial / booking targets in training
- Assign which accounts to dial (especially under-KPI clients)
- Keep them on time, dialing, and on pace — correct slippage same day
- Unblock AI bot / Hot Prospector / GHL / Slack / setting issues fast
- Grade quality, not only dial count
- Escalate client-context / relationship questions to Laura (not CEO first)

---

## 8. Booking-stack rules

- You are first line for **AI bot, Hot Prospector, booking/GHL
  automation**, and anything else that stops lead → appointment on the
  setting side.
- If you cannot fix it → escalate to **Laura** (she helps). If still
  stuck → **Christian**. If still stuck → **CEO**.
- Clear **OB setup error** (wrong/missing from onboarding) →
  **Christian direct** (skip the long ladder).
- Do **not** send routine bot/GHL tickets straight to Christian.
- Escalate to **CEO** via Fri Q&A / Planning for offer, pricing, major
  script doctrine, or system rebuild decisions.

## 10. Escalation map

| What came up | First owner | Next |
|--------------|-------------|------|
| Booking % / Show % / dial miss | **You** (diagnose + named fix) | Laura follows up |
| Rep late / missing / idle / wrong account | **You** | Laura if pattern |
| Reps off pace on dial / booking goals | **You** (same-day correct) | Laura follows up on named fix |
| AI bot / Hot Prospector / booking·GHL bug | **You** | Laura → Christian → CEO |
| Clear OB setup / checklist error | **Christian direct** | Laura gate / CEO |
| Client unhappy / relationship | **Laura** | CEO if churn/legal |
| Ads / CPL / CPQL / Opt-in % | **Christian** | Laura follows up |
| Offer, pricing, major doctrine | CEO via Fri Q&A / Planning | — |
| Setter hiring need | Leadership asks → **you help** | Laura/CEO own final hire decision |

**Booking-stack rule:** You are first line. Do **not** send routine
bot/GHL tickets straight to Christian.

---

## 11. Done for the day means

You can shut down when all of these are true:

1. Training ran
2. Setters showed up on time (or late/missing was handled same day)
3. Setters had clear dial targets and right-account assignments —
   and you know if they hit them / stayed on pace
4. Open AI bot / Hot Prospector / GHL bugs have owner + ETA or are
   escalated
5. Under-KPI clients have dial coverage scheduled if needed
6. CC / booking reds named for Laura (Mon/Thu) with a commitment
7. No setter without a manager for the day
8. Any open recruitment ask has a next step (not floating)
