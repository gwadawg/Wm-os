# Production Format Library

How you **film and edit** personal content. Distinct from **content formats**
(reel, carousel, trial-concept) in [`format-templates.md`](../../../.claude/skills/content-engine/format-templates.md).

When ideating or scripting, pick a production format first, then match content
format and pillar.

## Quick picker

| ID | Name | Resource cost | Scripting | Best for |
|----|------|---------------|-----------|----------|
| `yap` | Yap | Low | None — bullet prompt | Hot takes, beliefs, quick reactions |
| `vo-montage` | VO montage | Medium–high | Light — VO + shot list | Inspirational journey, lifestyle identity |
| `talking-head-broll` | Talking head + b-roll | Medium | Full reel with cut marks | Story arcs, tactical how-to |
| `concept-edit` | Concept edit | Medium | Hook + visual beats | Format lab, aesthetic identity, no-face tests |

## Format selection matrix

| Pillar | yap | vo-montage | talking-head-broll | concept-edit |
|--------|-----|------------|--------------------|--------------|
| Burn-the-boats | ✓ hot takes | ✓ milestones | ✓ primary | — |
| Extreme beliefs | ✓ primary | — | ✓ | — |
| Lifestyle / travel | — | ✓ primary | — | ✓ primary |
| AI + ops | ✓ quick takes | — | ✓ how-to | — |
| Format lab | ✓ trial | ✓ test | ✓ test | ✓ primary |

## yap

**Profile:** Talk to phone, minimal edit. One take or light trims. Captions
optional but recommended for retention.

### When to use

- Contrarian belief or hot take (Pillar 2)
- Quick reaction, rant, or "real talk" moment
- Trial a hook before investing in b-roll
- Low-energy day but still need output

### When not to

- Story needs visual proof or cutaways
- Inspirational / cinematic mood
- Tactical how-to with screen or demo

### Film checklist

- **Talent:** Self, direct to front camera
- **Gear:** Phone only; natural light or ring light
- **Location:** Car, desk, walk — anywhere; authenticity > production
- **Takes:** 1–3 max; pick best energy, don't over-polish

### Editor notes template

```
- Trim dead air at start/end only
- Jump cuts OK on pauses; no b-roll required
- Captions: full burn-in (recommended)
- Music: none or very low under voice
- Length: 15–45s; stop when point lands
```

### Resource cost

**Low** — highest volume format; best 10% scoring factor in weekly ideas.

### Script path (Phase 3)

Use **trial-concept** template in [`format-templates.md`](../../../.claude/skills/content-engine/format-templates.md).
Bullet prompt only: hook line + one supporting line. No full script.

## vo-montage

**Profile:** Inspirational voiceover + music + b-roll. Light scripting — VO
script and shot list, not word-for-word performance on camera.

### When to use

- Journey milestones, identity pieces (Pillar 1, 3)
- "This is the life I'm building" energy without talking head
- Travel, lifestyle, ambition montages
- Emotional arc over tactical explanation

### When not to

- Need direct accountability / harsh take (use yap)
- Tactical step-by-step (use talking-head-broll or carousel)
- Fast hook test (use yap or concept-edit)

### Film checklist

- **Talent:** VO record separately (quiet room or phone voice memo)
- **B-roll:** Travel, work, lifestyle — batch when traveling or on good days
- **Gear:** Phone b-roll; optional lav for cleaner VO
- **Music:** Pick track before edit; mood drives cut pace

### Editor notes template

```
- VO: clean, paced for inspiration (not rushed)
- Music: drives energy; duck under VO, swell on visual-only beats
- B-roll: match VO beats; 2–4s per clip; variety of wide/medium/detail
- Text overlays: optional hook line on open; avoid over-captioning
- Length: 30–60s
```

### Resource cost

**Medium–high** — needs b-roll library and edit time.

### Script path (Phase 3)

Use **reel** template with `body` as VO lines + `[VISUAL:]` b-roll cues per
beat. No on-camera `[LINE:]` unless hybrid open.

## talking-head-broll

**Profile:** A-cam direct address with b-roll cutaways on key lines. Marcel-style
UGC structure: hook → story/insight → CTA.

### When to use

- Story arcs with tension and turn (Pillar 1)
- Tactical how-to with visual proof (Pillar 4)
- Proof-heavy operator content (agency, systems, results)
- Swipe-adapted structures from @marcel.stxm

### When not to

- Pure aesthetic / no narrative (use concept-edit)
- Raw hot take with no supporting visuals (use yap)
- Fully off-camera inspirational piece (use vo-montage)

### Film checklist

- **Talent:** Self, A-cam talking head (tripod or propped phone)
- **B-roll:** Screen recordings, hands on keyboard, travel cutaways, proof shots
- **Script:** Mark cut points in script before filming
- **Takes:** Full read-through + pickup lines for b-roll inserts

### Editor notes template

```
- Open on talking head for hook (0:00–0:03)
- Cut to b-roll on mechanism, proof, or emotional beat
- Return to talking head for CTA
- Captions: full burn-in
- Music: low under voice; optional swell on b-roll
- Cut pace: medium; match Marcel-style story + CTA rhythm
- Length: 30–45s
```

### Resource cost

**Medium** — script + A-roll + some b-roll.

### Script path (Phase 3)

Use full **reel** template with `[VISUAL:]` and `[LINE:]` alternation and
explicit cut marks in `editor_notes`.

## concept-edit

**Profile:** Audio/visual-first. Face optional. Trending or original sound
design. Hook + visual beats — not a full spoken arc.

### When to use

- Format lab experiments (Pillar 5)
- Lifestyle aesthetic without talking head
- Trending audio with brand-adjacent message
- Shareable identity moments (ambition, travel, money energy)

### When not to

- Belief needs your voice and face for accountability (use yap)
- Complex story or tactical walkthrough (use talking-head-broll)
- Long inspirational narration (use vo-montage)

### Film checklist

- **Talent:** Optional — hands, POV, silhouette, or no person
- **Visuals:** Batch aesthetic clips; travel, city, work environment
- **Audio:** Trending sound or original beat; pick before edit
- **Text:** On-screen hook text often carries the message

### Editor notes template

```
- Lead with visual + audio hook in first 1s
- Text overlay: 1–2 lines max; readable font, high contrast
- Cut on beat; 1–3s per clip
- No talking head required; face optional
- Length: 15–30s
```

### Resource cost

**Medium** — edit-heavy, lighter on performance.

### Script path (Phase 3)

Use **trial-concept** for first test; upgrade to **reel** with visual beat
list only (no full spoken body).
