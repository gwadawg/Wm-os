# 01 — Anchor: Third-Voice Callback Framework

## Hook (on-screen + open line)

**Text overlay:** `They ghosted you. Call back as someone else.`

**Reframed open (caption or VO intro if needed):**
> You can save a lot of deals that fell out — if you stop sounding like the salesperson who already pushed them.

## Thesis

One clip, one tactic: **come in as a third voice** (customer success / file
closure) so the prospect lowers their guard, states the real objection, and you
can re-book without the pushy startup energy.
