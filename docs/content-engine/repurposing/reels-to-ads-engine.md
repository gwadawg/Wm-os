# Reels to Ads Engine

Pipeline: personal/business short-form that performs organically → adapted Meta ad creative for client or Waiz campaigns.

## When to repurpose

- Reel exceeded baseline (saves, shares, completion, DMs)
- Angle validated via trial-concept
- Message maps cleanly to a client ICP (with compliance review)

## Steps

### 1. Source selection

Pick from `personal/scripts/` or `business/scripts/` with `status: published` and note performance metric.

### 2. Lane check

| Source lane | Target |
|-------------|--------|
| Personal (generic insight) | Waiz business ad or personal boost only |
| Personal (mortgage/LO specific) | Client DNA after compliance |
| Business | Waiz acquisition ads |

### 3. Adaptation checklist

- [ ] Hook works without personal context
- [ ] ICP language from client DNA applied
- [ ] Compliance guardrails read (client pod)
- [ ] CTA matches funnel stage (TOF/MOF/BOF)
- [ ] Disclosure rules if testimonial-style

### 4. Output

- Client: new row in client creative batch or creative-studio output folder
- Waiz: acquisition marketing script doc

### 5. Handoff

Use [rm-creative-studio](../../../.claude/skills/rm-creative-studio/SKILL.md) or client DNA playbooks for final ad script + editor notes.
