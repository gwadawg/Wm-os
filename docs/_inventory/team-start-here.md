# Start Here — Waiz Team SOPs

## Purpose

Help every team member find the right procedures quickly. Official updates are published here from operations; if something looks out of date, tell Gabriel.

## Scope

All roles. Use your role folder first, then Company Basics for shared context.

## When To Use

- First day onboarding.
- Before starting a workflow you have not done recently.
- When you need a linked procedure from Related sections in any doc.

## Process

### 1. Pick your role folder

| If you are… | Open folder |
|-------------|-------------|
| Setter | 02 - Setters |
| Closer | 03 - Closers |
| Client Success | 04 - Client Success |
| Operations | 05 - Operations |
| Everyone | 01 - Company Basics |

### 2. Essential docs by role

**Setters:** Setter Daily Operations, Intro Call Qualification, No Shows And Show Rate.

**Closers:** Discovery Call Script, Demo Call Script, Objection Handling Hub.

**Client Success:** Constraint Troubleshooting, Fulfillment KPI Standards, CRM Infrastructure Overview.

**Operations:** OPS Manager Priority Ladder.

**Everyone:** Who We Are — Identity Core.

### 3. How updates work

Procedures are maintained centrally. When you see a conflict between this library and what you were told in Slack, follow the Doc here and flag Gabriel.

- You can reach your top three role docs in under 60 seconds from this page.
- Related links inside each doc point to other procedures without repeating full content.
