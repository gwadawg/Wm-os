End-of-day reporting standard — field-by-field for setters (closers section below).

# Overview

> **📌 NORTH STAR**
>
> Submit EOD when you wrap every working day — accurate numbers, pipeline cleared, coaching-ready roll-up.

- **Who:** Setter (see [daily checklist EOD block here](docs/acquisition/sales/setter-daily-checklist.md))
- **When:** When you finish for the day — no fixed clock-out
- **Output:** EOD form in sales Slack channel + CRM reflects today’s work

# Setter Admin (Before Submit)

Answer **yes** only if true:

| Task | Standard |
| --- | --- |
| **Setter KPI tracker** | Filled for the day |
| **Pipeline cleared** | No active lead without stage, disposition context, or GHL task (self or Gabriel) |
| **Dispositions correct** | Every lead spoken with today reflected in CRM — [rules below](#setter-disposition-rules) |
| **GHL tasks** | Your tasks current; Gabriel items assigned to Gabriel with context |
| **Hotlist** | [Hotlist rules below](#hotlist-setter) |
| **Notes** | No “called only” — per [lead messaging here](docs/acquisition/sales/setter-lead-messaging.md) |

**Not required:** Standing “audit next 3–4 days and mark FREE.” New bookings → [Watchshift / P1 here](docs/acquisition/sales/sop-watchshift.md).

# Hotlist (Setter)

High-intent leads flagged today (**Setter quality lead**, strong intro, waiting on reply):

- Touch each (call, value SMS, or task), **or**
- Create/update GHL task with next step and date

# Setter Disposition Rules

| Outcome | CRM |
| --- | --- |
| Strong pre-demo, not booked | **Setter quality lead** + note |
| Demo with closer booked | Booked stage + closer notes |
| Intro on setter calendar | Stage reflects intro slot |
| Not DFY fit | Boot Camp or lost — [financial qualification here](docs/acquisition/sales/disqualifying-financial-qualification.md) |
| No-show | No-show stage — [no-shows SOP here](docs/acquisition/sales/no-shows-maximizing-show-rates-setter-levers.md) |
| Junk / wrong number | Lost + brief note |
| Stuck call-book | Move stage or task — no limbo |

# Metrics (Form Fields)

Report honestly with brief context:

| Field | Report |
| --- | --- |
| Total dials | Count + note if light day |
| Conversations | Live connects |
| Booked demos | From outbound / intros |
| Calls confirmed | Demo confirmations (P3) |

# Roll-Up (Required)

Every call today: **name, outcome, next step.** Note objections and misaligned expectations for coaching.
