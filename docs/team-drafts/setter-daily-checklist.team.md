Single daily priority list for Pedro — same workflow every day; only calendar slots change.

# Overview

> **📌 NORTH STAR**
>
> Maximize qualified opportunities and demo bookings. Work P1→P7 in order. Deep execution lives in linked SOPs — not duplicated here.

- **Who:** Setter
- **When:** Every working shift — start prep, priority stack, EOD when you wrap (no fixed clock-out)
- **Voice:** Qualified conversations, acquisition system, strategic partner ([Identity Core here](docs/company/doctrine-identity-core-april-26.md))
- **Pricing / deal structure:** Escalate to Gabriel. Not DFY-qualified → Boot Camp, not demo ([financial qualification here](docs/acquisition/sales/disqualifying-financial-qualification.md))

# How To Use This Doc

1. **Start of shift** — quick prep (below).
2. **Always first** — drop-everything items only.
3. **P1–P7** — work in order; don’t drop to a lower priority until the one above is clear for this block.
4. **Intro calls (P1)** — run the [intro script here](docs/acquisition/sales/script-intro-call-basic.md); don’t duplicate call steps on this checklist.
5. **End of day** — submit [EOD here](docs/acquisition/sales/eod-report-sop-setters-closers.md) when you wrap.

# Start Of Shift

- [ ] Confirm watchshift channels are live (GHL, Slack notifications on)
- [ ] Glance at today’s calendar — any intro or demo appointments today?
- [ ] **GHL tasks:** Create a task for yourself when follow-up is needed. If Gabriel needs to act, create a task **assigned to Gabriel** — don’t rely on memory or Slack alone.

# Always First (Drop Everything)

Only these override the current priority block.

- [ ] **Watchshift alert** (Slack/GHL) → handle immediately per [Watchshift SOP here](docs/acquisition/sales/sop-watchshift.md), then ✅ or tag Gabriel on the thread
- [ ] **New inbound booking** → [Priority 1](#priority-1--intro-calls) — call now, don’t wait for the slot
- [ ] **Live intro or demo no-show** (you’re on the slot now) → [Priority 6](#priority-6--no-shows) protocol

# Texting Rules (All Priorities)

- **Value + context:** [Lead messaging SOP here](docs/acquisition/sales/setter-lead-messaging.md) — read lead file, form, and past texts before every SMS; notes on every lead you speak with.
- **Call first** in calling blocks; then text if no answer or **no SMS on file yet**.
- **Text replies do not stop outbound.** Reply, then jump back into dialing — pause for a live call only when it’s worth it now.
- Objection via text → steer toward booking; no long threads ([objection hub here](docs/acquisition/sales/objection-handling-hub.md)).

# Priority 1 — Intro Calls

**When P1 applies (call or take the live intro now):**

- Watchshift alerts → [Watchshift SOP here](docs/acquisition/sales/sop-watchshift.md)
- New inbound booking notification
- **Calendar intro slot is due** → pause P4–P7 until the call ends, then resume

**Checklist (this doc only):**

- [ ] Intro handled per [intro script here](docs/acquisition/sales/script-intro-call-basic.md) — all **5 call checklist** items before hang-up
- [ ] CRM outcome logged; GHL task for self or Gabriel if follow-up remains

_Framework: [qualification framework here](docs/acquisition/sales/intro-call-qualification-framework.md) | Boot Camp: [financial qualification here](docs/acquisition/sales/disqualifying-financial-qualification.md)_

# Priority 2 — Watchshift

Live monitoring block **and** alerts during the day. Cadence, alert types, Slack reactions, call paths: [Watchshift SOP here](docs/acquisition/sales/sop-watchshift.md).

- [ ] Watchshift channels active (GHL, Slack)
- [ ] Every item handled **immediately** — then ✅ on Slack, or **tag Gabriel** if needed
- [ ] Calls and SMS via [intro script here](docs/acquisition/sales/script-intro-call-basic.md) (opening type per situation)

# Priority 3 — Confirm Demo Appointments

Call prospects with a **demo** in the next **24–48 hours** and **every demo morning-of**. Don’t rely on automations alone.

**Script:** [Demo confirmation script here](docs/acquisition/sales/script-demo-appointment-confirmation.md)

- [ ] Pulled list of all demos in next 24–48 hours **and today**
- [ ] Called every booked prospect (word-for-word confirmation script)
- [ ] Double tie-down: date/time + verbal commitment + computer/Zoom
- [ ] Pre-call video: re-tie watch commitment or send correct asset ([pre-call videos here](docs/acquisition/marketing/pre-call-objection-videos.md))
- [ ] Attempted to move demo earlier if a sooner slot exists (within 24hrs ideal)
- [ ] CRM note per script template (confirm + video + watch Y/N)
- [ ] Unresponsive 24hrs out → WhatsApp text + voice note, Instagram DM per [no-shows SOP here](docs/acquisition/sales/no-shows-maximizing-show-rates-setter-levers.md)

# Priority 4 — LinkedIn (Outreach Only)

**Replies: do not respond.** Forward everything to Gabriel.

- [ ] All new LinkedIn replies **forwarded to Gabriel**
- [ ] GHL task if Gabriel needs context on a thread

**New outreach (30–60 min when P1–P3 clear)**

- [ ] 5–10 ICP post comments first
- [ ] Mined lists, groups, or engagement for prospects
- [ ] ~90 seconds research per prospect before connecting
- [ ] Connect requests sent (blank or signal micro-note — A/B per copy-angles)
- [ ] First DM sent to accepted connections
- [ ] One no-reply bump at 48–72 hours — then stop

_Process: [LinkedIn process here](docs/acquisition/outbound/linkedin/process.md) | Copy: [scripts and angles here](docs/acquisition/outbound/linkedin/copy-angles.md) | Compliance: [LinkedIn compliance here](docs/acquisition/outbound/linkedin/compliance.md)_

# Priority 5 — Power Dialer: New Leads

Only after P1–P4 are clear. Newest → oldest.

- [ ] Dialing new leads: newest → oldest
- [ ] Text after calling when needed; text replies per [texting rules](#texting-rules-all-priorities) — then back to dialing
- [ ] Objections via text steered to booking ([objection hub here](docs/acquisition/sales/objection-handling-hub.md))
- [ ] **Notes + pipeline stage** on every lead spoken with ([lead messaging here](docs/acquisition/sales/setter-lead-messaging.md))
- [ ] GHL task for callbacks you can’t hit today

_SOP: [Power dialer SOP here](docs/acquisition/sales/sop-power-dialer-new-leads.md)_

# Priority 6 — No-Shows

This week’s no-shows first, then archived. Per no-show:

- [ ] Waited 3 min — then called
- [ ] No answer → double-dialed immediately
- [ ] No answer → sent first text
- [ ] Called front desk (business hours) — “they booked a client generation call”
- [ ] **7 min past:** 3rd call from GHL + personal phone + Jeremy Miner text
- [ ] **10 min past:** final reschedule text
- [ ] Lead moved to no-show pipeline stage in CRM
- [ ] Archived no-shows worked after this week’s list is done

_SOP: [No-shows and show rate here](docs/acquisition/sales/no-shows-maximizing-show-rates-setter-levers.md)_

# Priority 7 — Call Center Work (B2C Leads)

Only when P1–P6 are fully exhausted for the current block.

- [ ] Confirmed P1–P6 clear before starting
- [ ] Working B2C leads per call center script system

_SOP: [Call center script factory here](docs/client-fulfillment/call-center/sop-call-center-script-factory.md)_

# Training Block

Fit training when the stack allows — don’t skip entirely.

- [ ] Training completed today (roleplay, recording review, or assigned module)

# End Of Day (When You Wrap)

Submit when done — flexible timing. Full standard: [EOD SOP here](docs/acquisition/sales/eod-report-sop-setters-closers.md).

**Admin**

- [ ] Setter KPI tracker filled out
- [ ] **Pipeline cleared** — every active lead has stage, disposition, or GHL task (self or Gabriel)
- [ ] **Dispositions correct** — today’s calls in CRM (booked demo, Boot Camp, lost, no-show, follow-up, etc.)
- [ ] Open **GHL tasks** up to date
- [ ] **Hotlist** followed up per EOD SOP

**Metrics to report**

- [ ] Total dials made
- [ ] Total conversations
- [ ] Booked demos (from outbound)
- [ ] Calls confirmed

**Roll-up**

- [ ] Full call roll-up — every call: name, outcome, next step
- [ ] Objections / misaligned expectations noted
- [ ] **EOD form submitted** to sales channel
