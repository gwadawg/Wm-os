How to run new-lead power dialer blocks — call order, texting, pipeline stages.

# Overview

> **📌 NORTH STAR**
>
> Fast dials with accurate CRM — every touched lead gets notes, stage, and next step before the next dial.

- **Who:** Setter
- **When:** **Priority 5** on [daily checklist here](docs/acquisition/sales/setter-daily-checklist.md) — after P1–P4 clear
- **Stop dialer** when watchshift or P1 interrupt fires → [Watchshift SOP here](docs/acquisition/sales/sop-watchshift.md), then resume

# Process

1. Confirm P1–P4 clear — don’t dial with watchshift backlog open
2. Pull queue **newest → oldest**
3. **Per lead:**
   1. **Call first** (live attempt)
   2. No connect → voicemail; **value text** if never texted — [lead messaging here](docs/acquisition/sales/setter-lead-messaging.md)
   3. Connect → [intro script here](docs/acquisition/sales/script-intro-call-basic.md) Opening 3 + FUN; book or route
   4. **Notes required** — every spoken-with lead
   5. Update **pipeline stage** immediately
   6. Callback or Gabriel input → GHL task
4. **SMS during block:** [texting rules](#texting-during-dial-blocks)
5. End block — no “called but not staged” limbo ([EOD pipeline cleared here](docs/acquisition/sales/eod-report-sop-setters-closers.md))

# Call Cadence (Default)

| Step | Action |
| --- | --- |
| 1 | Live call |
| 2 | Immediate second dial if no answer |
| 3 | Voicemail + short text (if appropriate) |
| 4+ | Retry per queue / GHL task |

**Voicemail:** Who you are + Waiz Media + why calling + callback ask — under ~20 seconds.

# Texting During Dial Blocks

[Lead messaging SOP here](docs/acquisition/sales/setter-lead-messaging.md) + [checklist texting rules here](docs/acquisition/sales/setter-daily-checklist.md):

- Call before text on new leads
- Text back while dialing → reply with value, **return to outbound**
- No long objection threads — [objection hub here](docs/acquisition/sales/objection-handling-hub.md)
- Pre-demo SMS needing Gabriel → [Watchshift SMS rules here](docs/acquisition/sales/sop-watchshift.md)

# Pipeline Stages And Outcomes

| Outcome | Action |
| --- | --- |
| Strong pre-demo, not booked | **Setter quality lead** + note + task |
| Intro on setter calendar | Book per intro script; stage = booked intro |
| Demo with closer booked | Demo stage + closer notes |
| Not DFY fit | [Financial qualification here](docs/acquisition/sales/disqualifying-financial-qualification.md) — Boot Camp or lost |
| Bad data | Lost + note |
| No answer, will retry | Follow-up stage or callback task |

# Escalation

| Situation | Action |
| --- | --- |
| Pre-demo SMS / quality lead needs Gabriel | [Watchshift SMS here](docs/acquisition/sales/sop-watchshift.md) |
| Pricing / policy | Tag Gabriel |
| Dialer outage | Gabriel / ops |
