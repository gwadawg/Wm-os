Speed-to-lead for live watchshift blocks and Slack/GHL alerts.

# Overview

> **📌 NORTH STAR**
>
> Handle every watchshift alert in minutes — contact the lead, update CRM, close the loop on Slack (✅ or tag Gabriel).

- **Who:** Setter (acquisition only — not B2C call center)
- **When:** Scheduled watchshift block **or** any watchshift alert during the shift
- **Inputs:** Slack/GHL alerts, lead record, [intro script here](docs/acquisition/sales/script-intro-call-basic.md), [qualification framework here](docs/acquisition/sales/intro-call-qualification-framework.md)
- **Outputs:** Lead contacted/dispositioned, Slack updated, CRM + GHL tasks current

# Watchshift Alert Types

Handle **immediately** when any of these fire:

| Alert | What to do |
| --- | --- |
| **SMS response** (pre-demo) | [SMS pre-demo rules](#sms-responses-pre-demo) — setter owns unless escalation applies |
| **New appointment booked** | Call to run intro **early** — don’t wait for the slot ([no-shows / speed-to-lead context here](docs/acquisition/sales/no-shows-maximizing-show-rates-setter-levers.md)) |
| **New lead in** | Call outbound; qualify and book per [intro script here](docs/acquisition/sales/script-intro-call-basic.md) |
| **No-show notification** | Opening 4 + [no-show protocol here](docs/acquisition/sales/no-shows-maximizing-show-rates-setter-levers.md) |

## Which Intro Opening To Use

| Situation | Opening |
| --- | --- |
| New booking — call **before** slot | Opening 2 (early intro) in [intro script here](docs/acquisition/sales/script-intro-call-basic.md) |
| New booking — slot is **now** | Opening 1 (booked call) |
| New lead (no intro yet) | Opening 3 (dialer / impromptu) |
| Missed intro | Opening 4 + no-show protocol |
| Live intro at scheduled time | Opening 1 |

Full dialogue: [intro script here](docs/acquisition/sales/script-intro-call-basic.md).

# SMS Responses (Pre-Demo)

**Scope:** Any SMS from a lead who has **not** completed a booked demo with the closer. Post-demo confirmations → [demo confirmation script here](docs/acquisition/sales/script-demo-appointment-confirmation.md) and [daily checklist P3 here](docs/acquisition/sales/setter-daily-checklist.md).

## Default — Setter Owns It

- Reply in GHL using [lead messaging SOP here](docs/acquisition/sales/setter-lead-messaging.md)
- Prefer a **call** when the thread is heating up ([checklist texting rules here](docs/acquisition/sales/setter-daily-checklist.md))
- **CRM notes required** on every substantive touch

## Tag Gabriel

Tag Gabriel on the Slack thread + GHL task when:

| Situation | Action |
| --- | --- |
| Message needs Gabriel’s voice or answer | Setter does **not** reply — tag Gabriel |
| High-value question (pricing nuance, policy, custom) | Tag Gabriel — do not guess |

After tagging: clear CRM state. Don’t mark ✅ until handoff is posted.

## Disposition — Quality Lead Pre-Booking

When lead is **good quality** but still pre-demo:

- Pipeline stage: **Setter quality lead**
- Note why + what’s pending
- GHL task for self or Gabriel

## When Handled (No Gabriel Needed)

1. Reply sent or call completed
2. CRM updated
3. **✅** on Slack notification

# Cadence (Required)

1. **Handle immediately** — treat alert as drop-everything until worked or waiting on prospect
2. **Close Slack loop:** ✅ when done, or tag Gabriel
3. **CRM / GHL** — per [daily checklist here](docs/acquisition/sales/setter-daily-checklist.md)

# During A Watchshift Block

1. Verify GHL + Slack alerts on
2. Work alert queue — inbound overrides outbound
3. Between alerts: call interested leads not yet qualified
4. SMS: follow [pre-demo rules](#sms-responses-pre-demo)
5. End block with handoff only if something is open

# Setting An Intro On Setter Calendar

When lead is busy: use Opening 3 BAMFAM in [intro script here](docs/acquisition/sales/script-intro-call-basic.md) — book on setter calendar ASAP.
