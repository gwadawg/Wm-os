# Lead Media Buyer PJ Comp + Expectations Design

## Purpose

Payment agreement and growth ladder for a new **Lead Media Buyer** (Brazil PJ):
Month-1 ramp, ongoing BRL base, skills-only level raises, and CPQL commissions that
start only after Level 2. Senior seat vs Christian (buying + progressive creative),
without locking a US-style high base.

## Status

**DRAFT — awaiting founder review of this spec** before drafting the PJ agreement
pack and implementation plan.

## Scope

| In | Out (for now) |
|---|---|
| PJ payment + expectations agreement design | CLT / US employment contract |
| L1–L4 BRL base ladder (skills-only unlocks) | Mentoring Christian as a level gate |
| CPQL commissions from L2+ | Creative throughput commissions |
| Payday on the 9th | Stickiness / consecutive-month bonuses |
| Shadow EOM before live commissions | Changing Christian’s locked Phase 1 plan |

## Design principles

1. **Month 1 is a ramp stipend** — flat base, no commissions; systems + supervised reps.
2. **Base holds then climbs** — L1 base stays R$4,000; raises only via published levels.
3. **One commission engine** — CPQL vs written per-account target; no second creative bonus formula.
4. **Commissions are a privilege of L2+** — prove scope first, then earn variable.
5. **Capability → salary; performance → commission** — creative depth unlocks levels, not a parallel cash plan.
6. **Margin-safe** — BRL band R$4k–7k ≈ ~US$780–1,360; variable only on quality (CPQL).
7. **Easy EOM** — eligible accounts → hits × R$100 → scorecard gate → pay on the 9th.
8. **Quarterly knobs** — rates, floors, grace, level criteria with 30 days’ notice.

## Approach (locked)

**Approach 1:** Mirror the *structure* of [Christian’s Phase 1](../../plans/2026-07-15-christian-media-buyer-comp-design.md)
(base + per-account KPI hits + scorecard gate + shadow EOM), adapted for:

- BRL + PJ
- Senior/lead scope + creative ladder
- **CPQL** (not CPL) as the paid KPI
- **R$100** per hit, **only at L2+**
- No book bonus in Phase 1

## V1 structure — monthly pay

### Month 1 (ramp)

| Component | Amount | Notes |
|---|---|---|
| Base | **R$4,000** | Flat; unconditional for the ramp month |
| Commissions | **R$0** | Not available in Month 1 |

### Month 2+ by level

| Level | Base (BRL) | Commissions |
|---|---|---|
| **L1** Lead MB | **R$4,000** | **None** |
| **L2** | **R$5,000** | **R$100** × eligible accounts at CPQL KPI |
| **L3** | **R$6,000** | Same commission rules as L2 |
| **L4** | **R$7,000** | Same commission rules as L2 |

Scorecard gate (L2+): month scorecard **≥ B** or commissions = **R$0** (base still pays).

Hard cash ceiling: **none**.

### Payday

- **Pay day: 9th of every month** (BRL).
- Pays **prior calendar month** base (by level then in force) + approved commissions.
- Example: September work → invoice/approve early October → paid **9 October**.
- If the 9th is not a banking day, pay the next banking day (confirm with accountant).

## Level ladder (skills-only)

Founder sign-off on a written checklist unlocks the new base **starting the next full
pay month** after sign-off (no retroactive base unless founder writes an exception).

| Level | Base | Unlock when he can… |
|---|---|---|
| **L1** | R$4,000 | Hired; completes Month 1 ramp |
| **L2** | R$5,000 | Manage all accounts · onboard a client · create a basic funnel · understand/write headlines · run KPI client reviews |
| **L3** | R$6,000 | Own creative process: clear analysis + scripts/concepts fully written for production |
| **L4** | R$7,000 | Produce and edit ads end-to-end |

**Explicitly not a gate:** mentoring Christian.

**L2–L4 unlock rule:** skills demonstration only (founder checklist). No required
scorecard streak or book-size threshold for the base bump.

## Role expectations (SOW summary)

**Seat:** Lead Media Buyer — senior buying seat + progressive creative ownership.
**Engagement:** Brazil PJ · invoices in BRL · not CLT.

**Core (all levels)**

- Own assigned Meta buying: structure, budgets, testing, hygiene
- Hit written per-account targets; flag booking/fulfillment issues early to Client Success
- Client-facing clarity (KPI reviews required for L2+)
- Operate inside Wm-os media-buying SOPs / Daily OS

**Creative (progressive)**

- **L1:** Learn system; contribute angles/notes; does not own packages
- **L2:** Buying + onboarding + funnel basics + headlines + KPI reviews

**Month 1 ramp**

- End of Month 1: founder check-in (stay L1 or start L2 checklist) — no auto-raise

## Commission rules (L2+ only)

### Hit

```text
actual CPQL = account ad spend that month ÷ qualified leads that month
HIT = actual CPQL ≤ written per-account CPQL target
      OR within 10% over target (Phase 1 grace ON)
```

- Paid KPI = **CPQL**, not CPL.
- Qualified lead = meets call-center pre-qualification criteria (same definition as
  fulfillment KPI standards).
- Company reference bands (e.g. ~US$20–29.99 “at KPI”) inform judgment; **pay uses the
  written per-account target**.

### Written target (required)

On file before month start (or within 5 business days of launch).

- He proposes; founder approves; filed on the EOM Sheet before the month counts.
- Geo/product-aware (tight geos get higher CPQL targets).

### Eligible account (scored)

All of:

1. Assigned to him for media buying that month.
2. Written CPQL target on file.
3. Ads meaningfully running (not paused all month).
4. Signal floor: spend **≥ US$1,000** and qualified leads **≥ 10**.
5. DFY or mid-tier — both at **R$100** per hit in Phase 1.

Paused / zero-spend / no-target / below floor → **out of pool** (neither help nor hurt).

### Payout formula

```text
if level < L2 OR scorecard < B:
  commissions = 0
else:
  commissions = hits × R$100

total = base(level) + commissions
```

Phase 1: **no book bonus**.

### EOM calculation (&lt;15 minutes)

1. List assigned accounts; drop non-eligible.
2. Per eligible: spend, qualified leads, CPQL vs target (+ grace).
3. `hits × R$100`.
4. If scorecard &lt; B → commissions = 0.
5. Total = base + commissions.
6. Founder approves → invoice → **pay on the 9th**.

Sheet columns:

`account | geo class | target CPQL | spend | qual leads | actual CPQL | eligible | hit | notes`

**EOM owner:** he prepares; founder approves before payment.

### Go-live for commissions

Cash commissions do **not** pay until:

1. He is signed off at **L2** (or higher).
2. Each scored account has a written CPQL target.
3. One **shadow EOM** month is run and founder signs off.

## Decisions locked

1. Engagement = **Brazil PJ**; currency = **BRL**.
2. Month 1 = flat **R$4,000**; no commissions.
3. L1 ongoing base = **R$4,000**; no commissions until L2.
4. Ladder: **4 → 5 → 6 → 7** (L2 skills / L3 creative packages / L4 produce+edit).
5. L2+ commission = **R$100** per eligible account at **CPQL** KPI.
6. Phase 1 grace **10% over** target **ON**; floor **US$1k spend / 10 qual leads**; no book bonus.
7. Scorecard ≥ B gate on commissions.
8. Payday = **9th** each month for prior month.
9. No mentoring-Christian gate.
10. Approach = structural cousin of Christian Phase 1; metric = CPQL; richer per-hit; later unlock.
