# Acquisition Script Boundary Rules

## Purpose

Prevent cross-use of acquisition sales scripts and fulfillment call-center scripts.

## Scope

Applies to all script execution and script editing in `docs/acquisition/sales/`.

## Non-Negotiable Rules

- Acquisition scripts are only for selling Waiz offers (setter/closer funnel).
- Do not use fulfillment call-center scripts in acquisition calls.
- Do not store acquisition script updates in fulfillment folders.
- Any B2C post-sign call flow belongs to fulfillment call-center docs.

## Allowed Acquisition Script Set

- [Intro Call Basic Script](script-intro-call-basic.md)
- [Discovery Call Script](discovery-call-script-2026.md)
- [Demo Call Script](script-demo-call.md)
- [Objection Handling Hub](objection-handling-hub.md)
- Related script operations via [Script Factory SOP](sop-script-factory.md)

## Routing Rule

If the conversation is client-side B2C or post-sign fulfillment, route to:

- [Client Fulfillment — Call Center](../../client-fulfillment/call-center/README.md)
- [Call Center Script Boundary Rules](../../client-fulfillment/call-center/script-boundary-rules.md)

## Escalation

- Unclear script ownership -> sales-leadership.
- Mixed-domain script draft detected -> stop and re-home before use.
