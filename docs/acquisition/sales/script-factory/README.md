# Script Factory — Reusable Building Blocks

## Purpose

Canonical **frameworks and patterns** used when drafting or updating acquisition scripts. Stage scripts (intro, discovery, demo) link here instead of duplicating methodology.

## Scope

Acquisition sales only. Process for creating scripts: [Script Factory SOP](../sop-script-factory.md).

## How to use

1. Start a script brief per [Script Factory SOP](../sop-script-factory.md).
2. Pull positioning from [WM Sales Intelligence Bible](../../intelligence/wm-sales-intelligence-bible.md) and [Identity Core](../../../company/doctrine-identity-core-april-26.md).
3. Apply relevant building blocks below — adapt wording to stage and role (setter vs closer).
4. Log published script changes in [Sales Script Version Change Log](../sales-script-version-change-log.md).

## Building blocks

| Block | Use when | Doc |
|-------|----------|-----|
| **Flip the Frame — company description** | “Give me the rundown” — reclaim frame (Framework 1) | [flip-the-frame-company-description.md](flip-the-frame-company-description.md) |
| **Intro ICP tracks** | Framework 2 “who we are” + demo pre-pitch by referral / marketing-system / forward→reverse | [intro-icp-tracks.md](intro-icp-tracks.md) |

## Adding a new block

- One framework per file under `script-factory/`.
- Include: core principle, when to use, generic pattern, Waiz/ICP adaptation, cheat sheet, related stage scripts.
- Link from this README and from [Script Factory SOP](../sop-script-factory.md).
